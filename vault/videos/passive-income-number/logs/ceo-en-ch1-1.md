## The orchestrator's open question — s10 / "the tank"

**It does not bear on ch1 SHIP.** The tank appears at s10, s46, s47 and s57. Nothing in
s1–s8 shows it, names it or sets it up, so there is no ch1 frame that a weaker s10 makes
wrong. Blocking a clean chapter on a chapter-2 asset would spend a render on the wrong
chapter. **My view, for the ch2 gate to rule with the frame actually on screen:**

1. **The brass-tap-on-a-plain-steel-body resolution is the storyboard's own declared
   fallback, not a sourcing failure.** §10's returning-object table already says it in
   as many words: *"the tap is what carries the rhyme, not the tank's silhouette"*, with
   the fallback written out — buy the wide frame, source the rest as tap/stream macros in
   the same material family. Six sheets did not fail; they landed on the plan B that was
   written before the first sheet was pulled.

2. **The callback is therefore safe.** s46/s47/s57 encode their beats in **tap position**
   (wide open → level low → barely cracked → a thin stream into a tin cup), and the tap is
   present in all four. The viewer will have been shown the object the callback lands on.

3. **The one real risk is a word the picture cannot support.** If 2.2's VO says *tank* over
   a frame with no vessel, that is the sound-off rule inverted — the picture arguing with
   the line — on the beat that plants style E's load-bearing device. **The cheap fix is in
   ch2's build, not in a seventh sheet:** s10 already carries a kicker and a statement, so
   have them name the object (`THE TANK`) as the tap is shown. A label costs nothing, uses
   no Lottie, and introduces the word and the picture in the same frame — which is all the
   analogy needs to be legal.

4. **Only if the steel body does not read as a vessel even with the label** does this become
   a real decision, and then the honest move is to change the metaphor's noun rather than
   keep sourcing. That is a creator call on a creator-approved line and it should not be
   made from text. Put the s10 frame in front of the ch2 gate and decide there.
