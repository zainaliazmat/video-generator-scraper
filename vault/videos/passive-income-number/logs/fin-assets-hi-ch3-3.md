**The pool's shape, for the next brief:** the cable-tangle family exists and is deep, but
it is overwhelmingly shot *upward against sky*, because that is the only way to isolate a
pole. A frame where the tangle itself fills the frame — the thing the ruling asked for —

**Sound-off test, all five questions:**
1. Type covered, what is this? *The wires — the line into the house.* An Indian viewer
   names an overhead cable pole on sight; that is the physical body of the internet, which
   is what the ruling identified as the thing nobody had fetched.
2. Does it argue with 3.8? No — it *carries* the second half. 3.8 is "यही सीधी बात … बहुत
   बड़ा और बहुत जल्दी बना दिया जाता है". Two hundred loops where six would do **is**
   over-provision; the excess is the object's own meaning, so the `stmt` does not have to
   lend it. (No still photograph carries *fast*; the `stmt` carries that, and the ruling
   already accepted that split as honest.)
3. Is the named thing in frame? Yes — the internet, physically.
4. Reused in this chapter? No. The chapter runs gullaks → abacus → abacus crop → fan →
   meter → stamps → balance → **cables** → bullock cart. Nothing else is an electrical or
   telecom object except s26's meter, which is a single instrument on a wall, not a mass.
5. Place / era / currency? No currency of any country, contemporary, and the location is
   not provable from the frame (declared, as s22 declares its pottery yard) — there is no
   signage, no script and no number plate anywhere in it. Nothing in it contradicts an
