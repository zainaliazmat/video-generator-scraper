### 6 · ⚠ A LIVE SYSTEM DEFECT: `class="stamp warn"` renders RED TEXT ON A RED FILL

This is the chapter's most useful finding and it is not a ch5 defect — it is in
`tools/scaffold/assets/blockframe.css`, and **storyboard §8 specifies exactly the markup
that triggers it**:

    blockframe.css:124   .stamp { … color: #0d1017; … }     <- dark ink on the role fill
    blockframe.css:138   .warn  { color: var(--warn); }
    blockframe.css:187   .stamp.warn { background: var(--warn); }

`.stamp` and `.warn` have **equal specificity (0,1,0)** and `.warn` is declared **later**,
so it wins the colour: the pill would have shipped as `#ef4444` text on an `#ef4444`
fill. Nothing catches it — `.stamp.warn` at :187 sets only the background, the contrast
pass reads text against the **scene**, not against the pill, and §8's own note about a
"false contrast failure" would have made a real failure look like the documented benign
one. Every prior `.stamp` in this repo is in a legacy composition with its own inline
CSS, so this is the first time the class pair meets `blockframe.css`.

**Patched LOCALLY, in the composition's own `<style>`, and reported rather than fixed in
place** — the same shape as the centred-padding and centred-arch-b-caps patches two
earlier chapters each re-derived before they were ported upstream:

    .stamp.warn { color: #0d1017; }      /* (0,2,0), restores the component's own ink */

**It is a component fix, not a token edit**: no colour value changes anywhere, and
`known_benign` stays empty. With it, `npm run check` reports **14/14 WCAG AA**, so the
"false contrast failure" §8 warns about did **not** materialise here and nothing needed
suppressing. ⚠ **The real home is `tools/scaffold/assets/blockframe.css` and this build
may not write there** — see Owed 1. Confirmed by eye at t = 31.50: dark ink on the red
pill.

⚠ **And one measurement beside it.** `.stamp` is the ONE type component in
`blockframe.css` that does not set `margin: 0`, so it is emitted as a `<div>`, not a
`<p>` — a `<p>` would carry its 1em UA margin into the flex stack. Separately, the
pill's `rotate(-4deg)` raises its far corner **30.5px** above its layout box against a
32px stack gap, i.e. **1.5px of clearance at the extreme right corner**. Under the
figure's own x-range the clearance is ~25px and the snapshot confirms no collision — but
on any future scene where a stamp sits under a WIDER focal, that number is 1.5px.
