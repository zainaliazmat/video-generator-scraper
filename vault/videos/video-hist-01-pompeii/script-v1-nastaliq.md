## Likhne ke usool (is script ma kaise likha gaya)

1. **Angrezi lafz bhi Urdu script ma** — taake parhte waqt nazar Latin/Urdu ke beech na
   toote. `Scientists → سائنسدان`, `DNA → ڈی این اے`, `video → ویڈیو`,
   `subscribe → سبسکرائب`, `channel → چینل`, `bakery → بیکری`, `gym → جِم`.
2. **Mushkil angrezi → aasan Urdu** (literary Urdu nahi): `volcano → آتش فشاں`,
   `eruption → پہاڑ کا پھٹنا`, `eyewitness report → آنکھوں دیکھی رپورٹ`,
   `harness → سواری کا سامان`, `admiral → بحری فوج کا سربراہ`, `fleet → بحری بیڑا`,
   `earrings → بالیاں`, `charcoal → کوئلہ`, `AD → عیسوی`, `per hour → فی گھنٹہ`.
3. **Sirf zaroori technical lafz** rehne diye (kahani inhi pe tikki hai):
   `پومِس`, `پائروکلاسٹک فلو`, `کالم کولیپس` — har ek turant Urdu ma samjhaya bhi hai.
4. **Bolne wali Urdu (SOV)** — chhote/darmiyane/lambe jumle mila kar; sawal-jawab,
   "ٹھیک ہے نا؟"، "ذرا سوچو"، seedhi baat — jaise koi dost sunata hai.
5. Numbers digits ma (`79 عیسوی`, `33 کلومیٹر`, `2,000 سال`).
