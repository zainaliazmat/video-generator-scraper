# Screenshots — captured source images

`{source-id}-{YYYYMMDD}.png`, one per captured page state.
Rules: [[../knowledge/fact-integrity]] §4 — screen-record the REAL page, URL visible in
frame, hold ≥3 s on screen, highlight exactly one row.

The point of saving them: if the agency changes the page after publish, the state you
actually cited still exists. Without that, a correction cannot be adjudicated.
